在自己的電腦上，把活動照片和一首歌做成有歌詞字幕的回顧 MV。安裝與操作可以交給你的 AI 助理。

複製下面這段提示詞，貼給 Claude、Gemini、ChatGPT 等 AI。能操作電腦的 AI 會直接幫你裝好；不能操作的，會一步一步教你。

需要 Python 3.10 以上與 FFmpeg，約 3 GB 空間。Mac 裝在 ~/MVStudio，Windows 裝在 C:\MVStudio（不要放在 OneDrive 同步的資料夾）。

  


  

    
自己安裝

    
    
      
  1. 下載安裝包並解壓縮。
    2. 
      
  2. Mac：把 app 資料夾內容複製到 ~/MVStudio，在終端機執行 ./setup.sh。
    3. 
      
  3. Windows：複製到 C:\MVStudio，雙擊 setup.bat。
    4. 
      
  4. 看到「環境就緒」後，執行 setup.sh serve（Windows：setup.bat serve）開啟網頁介面。
    5.
