# 勿虛心假意 — 體驗遊戲結算（undercoverGame）

法會「勿虛心假意」體驗遊戲的後台工具，依《體驗遊戲修正方案（Dry Run 回饋後）》第四節「後台：手機 PWA」實作。

- 前端：純靜態頁面，部署在 GitHub Pages（`publishHTML` repo，push 到 `main` 自動部署）
- 同步：Firebase Realtime Database（沿用 `pwa-boardgame` 專案，匿名登入），資料放在 `artifacts/undercoverGame/public/data/events/<活動代碼>`
- 離線單機模式完全不需要網路，資料只存在該支手機（localStorage）

## 操作說明書

[`guide.html`](guide.html)：給控場講師與助理主持人的完整操作說明（含畫面截圖），可從儀表板右上角「操作說明」開啟，也可直接分享網址或列印。截圖放在 `guide/`，由 `SHOTS=<資料夾> node test/smoke.mjs` 產生。

## 誰用哪個畫面

| 角色 | 網址 | 用途 |
|---|---|---|
| 控場講師（電腦） | `/undercoverGame/#/dash` | 建立活動、列印信封 QR、設定梯次與組別、選任務、開始／暫停、確認超時、看各組資源 |
| 助理主持人（手機） | 掃儀表板上的組別 QR 碼 | 確認組別 → 依座位掃信封綁定 → 每回合掃任務 QR、掃 3 位隊員判定 → 抄剩餘量；隨時可掃信封查角色與記錄 |
| 玩家（手機，僅連線） | 掃儀表板「玩家版」區塊的玩家入口 QR（`?player=活動代碼`） | 掃自己的信封 → 按住查看角色、目標、剩餘資源；揭牌後看身分與回顧 |
| 沒網路時 | `/undercoverGame/#/offline` | 手機自行建立組別、選任務、計時與確認超時；不同步、沒有儀表板 |

## 活動前準備

1. 控場講師開儀表板 →「建立新活動」，得到 4 碼活動代碼（整場活動所有梯次共用）。
2. 「活動前準備」→ 列印**貼紙**（A、B 套各 13 張，只有代號）與**對照表**（代號 ↔ 角色 ↔ 資源，工作人員專用）。
3. 依對照表把角色卡裝進貼了對應貼紙的信封，第二人核對打勾。
4. QR 碼全場固定；只有按「更新 QR 碼」才會重新配對，舊貼紙與對照表即作廢。
5. 對照表右下角有「離線載入 QR 碼」。手機曾連線開過本程式時，對照也會自動留在手機上。

## 每梯次流程

1. 儀表板「梯次與組別」：選梯次、輸入總人數（12 人自動分 6＋6、13 人分 6＋7），每組選臥底卡抽法 → 建立本梯次。
   - **實體抽（預設）**：學員從 6 張臥底卡實體抽出（6～7 人 2 張、8～9 人 3 張、10～11 人 4 張），綁定座位時掃到哪張臥底就是哪張。
   - **儀表板抽**：儀表板事先隨機抽定（可手動改），綁定時只接受抽中的臥底卡。
   - 臥底不區分破壞型／干擾型、不控制比例；判定時仍依卡片本身（破壞型被派中＝失敗，原因「人」）。
2. 「回合控制」顯示各組 QR 碼，助理主持人掃描加入、確認組別，再依座位順時針逐一掃信封綁定。
3. 全部綁定後：選任務 → 各組手機掃任務 QR（或按「直接載入目前任務」）→ 開始回合。
4. 手機掃出任務 3 人的信封（掃不到可點座位編號）→ 判定結果。系統自動依「人 → 金額 → 體力 → 特休 → 交通」判定，成功時只扣存款與特休、3 人平均分攤、不足由持有最多者補。
5. 5 分鐘到，儀表板出現「確認超時」，主持人按下才算時間失敗。掃錯可「撤銷重掃」。
6. 「下一回合」。揭牌後可在儀表板「顯示角色」。
7. 遊戲中需要修正時，儀表板「編輯模式」可調整每位玩家的資源與角色、角色初始值、任務條件；按「儲存並通知」後同步到助理主持人與玩家手機，並顯示修正提示（資料存在 `overrides/`、`live/<g>/adjust`、`live/<g>/adjlog`、`notices/`）。

## 首次部署

1. 在 Firebase 主控台 → `pwa-boardgame` → Realtime Database → 規則，把 [`database.rules.json`](database.rules.json) 裡 `artifacts/undercoverGame` 這一段**合併**進現有規則（不要整份覆蓋，否則其他 PWA 的規則會被蓋掉）。
2. 把 `publishHTML` 推上 `main`。

## 檔案

| 檔案 | 說明 |
|---|---|
| `modules/rules.js` | 角色、任務、分組、判定與扣除（純函式） |
| `modules/session.js` | 資料層：連線寫 Firebase、離線寫 localStorage，共用多路徑更新 |
| `modules/dashboard.js` | 控場講師儀表板 |
| `modules/print.js` | 貼紙與對照表列印頁（A4） |
| `modules/phone.js` | 助理主持人手機（連線／離線） |
| `modules/player.js` | 玩家版：掃自己的信封、按住查看角色（防偷看）、揭牌回顧 |
| `modules/editor.js` | 儀表板編輯模式（玩家資源／角色、角色初始值、任務條件） |
| `modules/notice.js` | 修正通知橫幅 |
| `modules/spypick.js` | 臥底卡抽法選擇（實體抽／儀表板抽） |
| `modules/ui.js` | 共用元件、QR 產生（qrious）與掃描（BarcodeDetector／jsQR） |
| `test/rules.test.mjs` | 以修正方案 6 人組試算驗證扣除：`node test/rules.test.mjs` |
| `test/smoke.mjs` | 瀏覽器冒煙測試（記憶體版資料庫）：先 `python3 -m http.server 8765`，再 `node test/smoke.mjs` |

## 任務條件

| 任務 | 條件（3 人合計） |
|---|---|
| 出國開荒（示範） | 存款 51,000、特休 39 天 |
| 輪值司機 | 特休 15 天、汽車 2 台 |
| 大專夏令營 | 體力 60、存款 18,000 |
| 旅遊辦道 | 存款 36,000、遊覽車 1 台（或汽車 3 台） |
| 秋季祭典幫廚 | 體力 80、汽車 2 台（只算體力＋車輛，不扣除） |
| 災後復原（備用） | 體力 100、特休 12 天 |

## 注意

- 手機相機需要 HTTPS（GitHub Pages 即可）。iOS 上若相機無法開啟，可用掃描視窗下方的手動輸入（輸入 4 位代號數字即可）。
- 儀表板會請求螢幕常亮（Wake Lock）。
- 手機畫面上的角色查詢含角色身分，請勿讓學員看到。
