⚡ 快速上手（5 步驟）

  1. 1
    開啟網址點上方按鈕，或用手機瀏覽器（Chrome / Safari）開啟網址。
  2. 2
    開啟或拖曳 PDF支援一次選取多份 PDF 直接合併成一份；有密碼保護的 PDF 也能開啟（密碼只留在這次操作，不會被儲存）。
  3. 3
    編輯內容排序 / 旋轉 / 刪除頁面，或加上文字、畫筆、螢光筆、簽名、印章、圖片等標註；也可以填寫並送出 PDF 表單。
  4. 4
    （需要時）掃描檔辨識文字用左上角「OCR」功能，把掃描的中文／英文 PDF 轉成可搜尋、可複製的文字，也能用 Ctrl/⌘+F 直接搜尋內容。在 OCR 視窗可選擇「辨識方向」：橫書或直書。
  5. 5
    匯出成果完成後點「匯出 PDF」下載、另存新檔，或用系統「分享」直接傳給別人、存到雲端硬碟。
✅ 編輯到一半不小心關掉頁面也不用擔心：系統會自動保存草稿，下次開啟會問你要不要繼續上次的內容。

📲 安裝成手機 APP（建議）

安裝後可離線使用，也能從手機的「分享」選單直接把 PDF 傳進 PDF 工坊處理。

  1. 📱
    iPhone / iPad（Safari）開啟網址 → 點下方工具列的「分享」圖示 → 選「加入主畫面」。
  2. 🤖
    Android（Chrome）開啟網址 → 點頁面上方「安裝 APP」按鈕，或點 Chrome 選單中的「安裝應用程式」。
⚠️ 若要用「分享」功能把手機裡的 PDF 直接傳給 PDF 工坊處理，Android 手機務必用上述方式完整安裝成 APP，單純加書籤或捷徑無法出現在分享清單中。

❓ 常見問題

從 LINE 點連結打不開，或畫面跑版、無法操作？

連結已加上參數讓 LINE 自動改用手機的系統瀏覽器開啟。如果還是遇到問題，可以長按連結選擇「用瀏覽器開啟」，或直接複製網址貼到 Safari／Chrome 開啟。

Android 手機「分享 PDF」時，分享清單找不到 PDF 工坊？
  1. 先從主畫面或「設定 → 應用程式」移除舊的 PDF 工坊。
  2. 用 Chrome 重新開啟 PDF 工坊網址。
  3. 點頁首「安裝 APP」，或 Chrome 選單的「安裝應用程式」。
  4. 安裝完成後重新開啟一次 PDF 工坊。
  5. 之後從檔案管理員或其他 APP 分享 PDF，就能選到 PDF 工坊。
忘記密碼的 PDF 可以打開嗎？

不行，開啟有密碼保護的 PDF 仍需要輸入正確密碼；密碼只保留在這次操作的記憶體中，不會被儲存或上傳。

手機上匯出 PDF 後，要去哪裡找檔案？

沒有檔案選擇器的手機（例如 iPhone、部分 Android）會改用系統「分享」，可在分享面板選擇「儲存到檔案」、雲端硬碟，或直接傳給其他 APP。若畫面顯示「PDF 已建立」視窗，再點一次「開啟系統分享」即可，不會重新產生檔案。

OCR 辨識很久／很卡，怎麼辦？

可以只針對目前頁、所選頁面做辨識，不用整份都跑，能明顯縮短等待時間。已經有可搜尋文字的頁面系統會自動略過。

古籍、經典或直排的文件可以辨識嗎？

可以。在 OCR 視窗的「辨識方向」選「直書（繁體中文直排）」即可；選擇會被記住；直排標點可能變成半形、模糊掃描準確度較低，重要文件請再校對。

我的 PDF 內容會不會被上傳到網路上？

不會。所有解析、編輯與匯出都在你自己的瀏覽器裡完成，文件內容不會傳送到任何後端伺服器。
