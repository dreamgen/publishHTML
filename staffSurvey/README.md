# 服務人員調查 (staffSurvey) PWA

天達堂區幹部用手機查閱服務人員資料、當面或電話做排班問卷，並把結果寫回〈服務人員名冊〉xlsx 的工具。**所有資料只在手機端處理與保存，不上傳。**

---

## 使用流程

1. **第一次開啟**：設定 PIN（至少 4 碼）。
2. **匯入名冊**：選〈服務人員名冊_115.xlsx〉。讀取〈服務人員名冊〉與〈參考名冊〉兩張工作表，之後就記在手機裡，不用再找檔案。
3. **搜尋人員**：可用姓名、編號、區、班別、帶隊角色、社團搜尋（空白分隔多個關鍵字＝同時符合）；可依區、問卷狀態（未填／已填／待寫回）、來源（115有服務／高出席未服務／參考名冊／問卷新增）篩選。
4. **查閱人員資料**：基本資料、115 年各班出席（次數／有效場次）、115 年服務紀錄（場次、平日天數、7 天內重複、廚務／服務組／禮節／忠恕／交通）、資料備註、問卷摘要與電話（可直接撥打）。
5. **問卷調查**：沿用〈天達堂服務人員問卷〉2026-09 版 7 部分 31 題（條件題自動顯示／隱藏）。從名冊開問卷會預先帶入姓名、所屬區、乾坤與年齡，答案邊填邊自動加密儲存。
   - 名冊外的人（新人、從沒服務過的道親）用「新增問卷」；填了姓名若名冊有同名的人，會提示改記在他名下。
6. **寫回名冊**：「匯入匯出」→「下載名冊 xlsx」，得到 `原檔名_問卷回填_YYYYMMDD.xlsx`。

## 寫回名冊的規則

以最後一次匯入的名冊檔為底（ExcelJS 讀寫，保留格式、公式、凍結窗格、篩選、下拉選單），只動以下內容：

| 名冊欄位（黃底） | 來源題目 | 換算 |
|---|---|---|
| 工作狀態 | A5 | 全職上班／兼職/彈性／退休/家管／學生（名冊下拉選項） |
| 平日可請假天數/年 | B1 | 不用請假→「不需請假」；要請假→天數；平日沒辦法→0 |
| 會開車/可載人 | E1、E2、E4、E5 | 有車且願載人→會開車可載人；有車只載自己或可載 0 位→會開車不載人；其他人依 E4/E5 是否需要接送→不開車需接送／自行搭車 |
| 出發地點(行政區) | E3 | 原文 |
| 一年願意服務次數 | B4 | 原文 |
| 可支援項目 | C1、C2、C3、C5、C6、C7、E6 | 「可做：…；願學：…」 |
| 116年意願備註 | B1–B3、B5、B6、C4、D1、D2、E2、E4、E5、F1–F3、G1 | 分號串接的摘要 |
| 年齡層 | A4 | **只在名冊沒有年次時**才以問卷年齡覆蓋公式 |

- **名冊外新增的人**：加在〈服務人員名冊〉最後一列，來源＝「問卷新增」，資料備註註明「編號待補」。
- **參考名冊的人**：不改〈參考名冊〉，只出現在〈問卷明細〉。
- **〈問卷明細〉工作表**：每份問卷一列、完整 31 題欄位（與線上問卷的 CSV 彙整欄位相同），最後一欄 `_raw`（隱藏）是原始答案 JSON。
- **〈說明〉工作表**：新增／更新一列「問卷回填」紀錄。

把匯出的 xlsx 再「更新名冊」匯入（同一支或另一支手機），會依 `_raw` 合併答案（較新的優先），可用來交接或合併多位幹部的調查進度。

## 其他匯入匯出

- **匯入線上問卷檔**：〈天達堂服務人員問卷_線上填寫.html〉存下的 `.json`（`type: tiandatang-survey`）可多選匯入，依姓名＋所屬區對應名冊；對不到的列為「問卷新增」。
- **加密備份／還原**：整包（名冊、原始 xlsx、問卷、設定）以目前 PIN 加密成一個 `.json`，還原時輸入建立備份當下的 PIN。

## 資料保護

- 名冊、原始 xlsx、問卷答案、設定都存在 IndexedDB，以 **PBKDF2-SHA256（310,000 次）從 PIN 衍生的 AES-256-GCM 金鑰**加密；金鑰只在解鎖期間存在記憶體。
- 離開 App 超過設定時間（預設 5 分鐘）自動上鎖；PIN 連錯 5 次後開始延遲。忘記 PIN 無法救回，只能清除後重新匯入。
- `index.html` 設定 Content-Security-Policy：只能載入本站檔案、`connect-src 'self'`，頁面無法把資料送到其他網站。ExcelJS 放在 `vendor/`，不依賴 CDN。
- iPhone Safari 對「沒加入主畫面」的網站可能在 7 天未使用後清掉資料，請安裝成 App 並定期備份。

## 檔案

```
staffSurvey/
├── index.html            # 版面與樣式（含 CSP）
├── app.js                # 加密儲存、名冊、搜尋、人員頁、問卷、匯入匯出
├── survey.js             # 問卷題目定義（與線上問卷相同）＋名冊摘要換算
├── vendor/exceljs.min.js # ExcelJS 4.4.0（MIT，授權見 exceljs.LICENSE.txt）
├── manifest.webmanifest
├── sw.js                 # 預先快取 App 外殼，可完全離線
└── icons/
```

更新 `app.js`／`survey.js` 等檔案後，記得把 `sw.js` 的 `SW_VERSION` 加一。
