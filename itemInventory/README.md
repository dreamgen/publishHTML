# 📦 物品盤點站 (`itemInventory/`)

分組拍照登錄盤點物品，盤點後統一投影展示，讓大家一起決定「續留、丟棄、其它處理方式」的 PWA 工具。

## 主要功能

1. **雙模式支援**
   - **☁️ 雲端多人同步（Firebase RTDB）**：建立場次取得 6 碼代碼與 QR Code，各組手機掃碼即可分組拍照上傳，投影端即時同步顯示。
   - **💻 本機單機／雙視窗模式**：不需網路或 Firebase 規則即可使用；圖片儲存於 IndexedDB，同瀏覽器開兩個分頁（一頁登錄、一頁投影）可透過 `BroadcastChannel` 即時同步。
2. **分組拍照登錄**
   - 支援手機直接開啟相機拍照或從相簿選取，自動轉正 EXIF 方向並壓縮至 250KB 以內。
   - 可選擇預設組別或現場新增組別，並記住上次輸入的存放位置與盤點人，方便連續建檔。
   - 盤點組可先標記「初步建議」（建議續留／建議丟棄／建議其它），供會議討論參考。
3. **📺 投影決議模式**
   - 高對比深色全螢幕介面，支援 Wake Lock 防止螢幕休眠。
   - 逐項放大展示照片、數量、位置與備註，提供 **續留 / 丟棄 / 其它處理 / 暫緩待議** 四大按鈕與快速去向標籤（轉贈、二手拍賣、維修後再議、移交其他單位、資源回收變賣）。
   - 支援鍵盤快捷鍵（`←`/`→` 切換項目、`1` 續留、`2` 丟棄、`3` 其它、`0` 待議、`Esc` 退出）與「只看待議項目」、「決議後自動下一項」。
4. **統計與匯出**
   - 即時統計各決議數量，支援組別／狀態／關鍵字篩選。
   - 支援匯出 **CSV（Excel 相容 UTF-8 BOM）**、**完整 JSON 備份（含照片）**，以及 **列印／存 PDF 清冊**。

## Firebase 規則設定

若使用雲端多人同步，請將 `itemInventory/database.rules.json` 的規則合併進 Firebase Realtime Database 規則中（路徑 `artifacts/itemInventory/public/data`）。
