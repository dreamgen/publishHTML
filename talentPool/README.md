# 人才庫查詢 (talentPool)

天達堂〈人才庫總名冊〉手機查詢工具：匯入 xlsx 一次存在手機，快速搜尋、篩選人選，勾選後複製或分享到 LINE。

## 資料
- 讀取工作表〈確定的姓名（已登錄天達名冊）〉與〈姓名疑似可用（不在官方名冊中）〉（後者標示「待校核」），依表頭名稱對應欄位，欄位順序變動也能讀
- 匯入後解析成 JSON 存在 IndexedDB（未加密）；**名冊不放進 repo、不上傳**；頁面 CSP 禁止對外連線
- 重新匯入新版 xlsx 會覆蓋舊資料，仍存在的已選人選會保留；選單可刪除本機資料
- 年齡＝今年民國年 − 年次

## 功能
- 搜尋：姓名、編碼、道職、區域、單位、推薦組別、2022–2026 歷年職務與班別全文；空白分隔＝多關鍵字同時符合
- 篩選（全螢幕大字設定頁）：每個條件做成大按鈕卡片，按鈕上即時顯示「選了會有幾人」，0 人的選項變淡；年齡、出席、服務年數有快速區間按鈕＋−／＋ 微調；頂部即時顯示符合人數；可「存成常用」條件，主畫面一鍵套用；選單可切換字級（標準／大／特大）
- 篩選項目：名冊來源、乾坤、區域、年齡區間、2026 出席次數 ≥、服務年數 ≥、推薦組別（任一／全部）、官方道職、主要單位、參與項目（可選年度或任一年）
- 排序：2026 出席、歷練紀錄、服務年數、年齡、姓名
- 點卡片看完整資料（歷年職務依來源分組）；勾選框加入「已選」，可全選目前結果
- 分享：自訂標題、勾選要帶的欄位、單行／分行格式，可直接修改預覽；複製、分享 LINE（line.me/R/share）、系統分享
