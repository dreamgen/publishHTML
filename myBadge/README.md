# 道場名牌 PWA

## 名牌設計

從名牌右上角鉛筆、管理名牌或展示畫面的「編輯此名牌」開啟編輯器。

- 每張卡片各自保存版面與文字設定；QR Code 內容不會因編輯文字而改變。
- 姓名、班級名稱、學號預設引用預設名牌；預設名牌本身可直接輸入文字。
- 每個欄位可自行輸入，或指定其他名牌的來源欄位。引用會即時跟隨來源更新。
- 可新增最多 20 個欄位、改欄位名稱、排序及移除。空白文字不展示。
- 三種版面：經典直式、左右分欄、簡約識別證。
- 四組配色、自訂雙色、純色或漸層；可開啟每 8 秒輪換配色。
- 簡約版使用白色卡面與主色邊線；其他版面在抬頭區呈現純色或漸層。
- 即時預覽，按「儲存版面」才寫入本機。取消不變更資料。
- 循環／遺失引用會提示並阻止儲存。刪除來源名牌時，直接引用者會保留當時文字並轉為自行輸入。
- 更換預設名牌會先保留新預設名牌目前引用的文字；可能產生無效引用時不套用變更。

## 相容性

舊資料自動補上預設欄位及設計；匯出備份版本為 2，仍可匯入舊版 JSON。相同 ID 不重複匯入。名牌資料保存在本機瀏覽器。

## 驗證

執行 `node myBadge/tests/design.test.cjs`（從 publishHTML 目錄）。
涵蓋舊資料、預設引用、文字同步、自行覆寫、循環引用、刪除保留、QR 獨立與備份往返。

本機瀏覽器已驗證欄位編輯、分欄／翡翠配色儲存、另一張名牌同步文字與 390px 手機顯示。尚需使用實機相機驗證 QR 掃描及安裝版離線升級。
