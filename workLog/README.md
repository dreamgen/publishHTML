# 工作行程記錄 (workLog) PWA

往返客戶現場與辦公室的外勤工作者專用工具。支援手機離線打卡、記錄停留時間與工作成果、產生結構化純文字日報寄信給主管，以及月底一鍵匯出 Excel 專用工時統計 CSV。

---

## 核心設計理念與功能

### 1. 今日行程（外勤打卡與時間軸）
- **抵達打卡**：
  - 快速點選常用地點（自動依使用頻率排序）或直接輸入新地點（自動加入常用清單）。
  - 抵達時間預設為當前時刻，亦可自由點選調整。
- **進行中即時追蹤**：
  - 打卡後顯示「進行中」卡片，即時計算並更新停留時間（每 20 秒及回到前景時自動更新）。
  - 單擊「本日待辦」或「常用工作內容」即可快速加入本次行程的工作項目，亦可手動輸入。
- **離開與時長計算**：
  - 按下「離開」自動結算時長，完整支援跨午夜計算。
  - 行程時間軸中自動計算並標示兩段行程之間的「移動／空檔」時間。
- **自動離開偵測**（v1.1）：
  - 已打卡時持續比對目前位置與打卡點的距離：超過 300 m 跳出「你似乎已離開」提示（可選「還沒離開」暫停 30 分鐘），超過 1 km 自動結束打卡並可一鍵「復原」。
  - 已打卡狀態下直接在下一個地點打卡，會自動結束上一個行程。
  - 離開時間待確認的行程會以黃框標示，提供「最後在場／推算」快速採用或自訂。
- **靈活補登與編輯**：
  - 忘記打卡可隨時「補登」任何一天的完整行程。
  - 既有行程可隨時編輯地點、抵達／離開時間、工作內容、備註或刪除。
- **待辦清單管理與前日帶入**：
  - 支援多行貼上快速建立待辦。
  - 隔天在待辦區按一下「帶入前一工作日未完成＋明日計畫」，自動找出最近一個有紀錄的工作日並匯入未完成項目。

### 2. 每日覆盤（成果沉澱與明日規劃）
- **頂部指標**：快速彙總當日「工作時段跨度」、「駐點合計時數」與「待辦完成比例」。
- **行程成果填寫**：每個行程下的每項工作內容皆有獨立的成果欄位（如測案數量、缺陷回報狀況等）。
- **待辦核對**：勾選確認當日各項待辦之完成狀態。
- **今日總結與明日計畫**：撰寫總結、阻礙與明日待辦，明日計畫將供次日一鍵帶入。
- **無縫產出**：點擊「產生本日報告」即可直達日報分頁。

### 3. 報告統計（日報發送與月工時 CSV）
- **單日純文字日報**：
  - 結構清晰的純文字報告，整合工作時段、駐點總計、行程明細與成果、待辦進度、總結及明日計畫。
  - **寄信給主管**：一鍵開啟系統郵件用戶端（mailto），自動帶入收件人、副本 CC、自訂格式主旨與日報全文。
  - **複製全文與社群分享**：支援一鍵複製到剪貼簿，或透過 Web Share API 直接分享至 LINE、Teams、Slack 等。
- **每月工時統計**：
  - 統計當月出勤天數、駐點總時數、行程段數及每日平均工時。
  - 各地點駐點時數視覺化長條圖與占比分析。
  - 每日明細清單，點擊可直接跳轉至該日行程檢視。
- **雙份 CSV 匯出**：
  - **統計表 CSV**：月出勤彙總、地點占比統計表、每日時數表。
  - **行程明細 CSV**：單月每筆行程之抵達、離開、停留分鐘、工時、離開方式（手動／自動偵測／偵測提示確認）、離開時間是否待確認、內容、成果、備註及 GPS 座標。
- **待確認提醒**：日報頁會列出離開時間待確認的行程；寄信、複製、分享前若仍有待確認項目會再詢問一次。
  - 輸出採用 **UTF-8 含 BOM（`\uFEFF`）**，在微軟 Excel 中直接開啟不亂碼。

### 4. 設定（自訂與備份）
- **基本資料**：姓名（署名）、主管 Email（支援多位逗號分隔）、副本 Email、主旨自訂範本（支援 `{date}`、`{name}` 變數）。
- **GPS 定位開關**：控制是否記錄打卡經緯度與自動選點。
- **自動離開偵測**：可開關，並調整「提示距離」（預設 300 m）與「自動離開距離」（預設 1000 m，需大於提示距離）。
- **常用地點與工作內容自訂**：可自由新增、修改名稱、上移排序、刪除，或手動更新地點之 GPS 座標。
- **備份與還原**：支援完整 JSON 檔案匯出，匯入時提供「合併」或「取代」兩種模式，換手機時輕鬆無痛轉移。

## 重要使用注意事項

1. **GPS 智慧選點**：
   - 某個常用地點第一次打卡時（精確度良好時），系統會自動記住該地點之經緯度座標。
   - 往後在 300 公尺半徑範圍內開啟打卡時，系統將自動為您選取該地點。
   - 所有座標資料僅保存在本機裝置，不會外流。
2. **自動離開偵測的限制與判定規則**：
   - PWA 只有在 App 開在前景（螢幕亮著）時能讀取定位；App 在背景或鎖屏期間離開，會在**下次開啟 App 時補判**。
   - 判定需連續 2 次（間隔 ≥ 10 秒）或持續 2 分鐘在範圍外；誤差大於 150 m 的定位略過，並以「距離 − 誤差」判斷，避免大樓內 GPS 飄移誤判。
   - 離開時間：連續監測中取第一次超出範圍的時間；補判時若 15 分鐘內曾確認在場，直接採用「最後在場時間」；否則記為「推算時間」（現在 − 依距離以時速 25 km 估算的交通時間）並標示**待確認**。
   - 在客戶處時常打開 App（例如記錄工作內容）會更新「最後在場時間」，讓補判更準確。
   - 地點沒有座標、打卡時也沒有定位的行程無法自動偵測。
3. **公開 Repo 預設清單**：
   - 為了維護個人隱私與開源安全性，預設地點僅保留「公司」與「在家（遠端）」，客戶名稱請依個人需求於「設定」中自行新增。
   - 常用工作內容預設包含 QA 與軟體測試常見項目（如需求訪談、測案撰寫、測試執行、缺陷回歸等），均可在設定中依業務屬性修改。
4. **資料儲存機制（本機保存）**：
   - 本工具為純前端架構，所有行程與設定資料均存放在手機瀏覽器的 `localStorage` 中。
   - 清除瀏覽器快取或網站資料會導致紀錄遺失，強烈建議定期至「設定」頁面點選「⬇️ 匯出備份（JSON）」將檔案備份至雲端或電腦。
5. **郵件內文長度限制**：
   - 由於各系統及行動郵件 App 對於 `mailto:` 協定的 URL 字元長度限制不一，若日報內容較多時可能出現內文被截斷的情況。
   - 遇到此狀況時，請直接使用「📋 複製全文」按鈕，再開啟郵件 App 貼上即可完整保留。

## 技術架構

| 項目 | 技術規格 |
|------|----------|
| UI 框架 | 原生 HTML5 + JavaScript（ES6+） |
| 樣式工具 | Tailwind CSS (CDN) + 響應式行動端介面 (SafeArea 支援) |
| 本機儲存 | LocalStorage（鍵值 `workLog.v1`）+ StorageManager Persist 請求 |
| 定位服務 | HTML5 Geolocation API（高精度定位 + Haversine 距離演算法） |
| 離線支援 | Service Worker 快取（Stale-While-Revalidate 策略） |
| PWA 規格 | Web App Manifest，支援「加入主畫面」獨立運行 |
| 匯出編碼 | CSV UTF-8 with BOM (`\uFEFF`)，相容 Microsoft Excel |
