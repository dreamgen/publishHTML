## 已修正的問題

| 問題 | 修正及驗證 |
| --- | --- |
| 舊世代未同步內容可能只剩提示，無法取回文字 | 每個寫入者／世代保留完整救回快照，與逐筆待送操作原子存入 IndexedDB；清空後只提供救回，不自動回填。N10 驗證重連與再次重新整理後仍可取回 |
| 每次輸入都留下完整獨立備份，斷線期間空間需求快速增加 | 改成每個寫入者／世代共用一份更新中的救回快照，outbox 僅存增量及快照參照；保留不同分頁的獨立紀錄 |
| 資料庫規則使用 RTDB 不支援的檢查方法 | 改用子欄位驗證與未知欄位拒絕；規則已由真正 Database Emulator 載入並通過允許／拒絕測試 |
| 文件切換時已送出的舊操作可能晚到，影響同步狀態 | 寫入前重查控制器生命週期與世代，舊世代失敗不污染新文件狀態；規則仍是阻擋舊寫入的最後防線 |
| 同步權限錯誤後按重試可能沒有重建 metadata 監聽 | 重試重新建立監聽及載入伺服器上的現行世代；N7 包含重試後的清空與復原 |
| 桌面記事本可能蓋住正式答案儲存按鈕 | 側欄開啟時同步縮小固定儲存列；N8 驗證按鈕邊界位於面板之外 |
| 手機全螢幕仍可將鍵盤焦點移至背後作答頁 | 手機模式使背景 inert、限制面板內 Tab 導覽，返回桌面時恢復；N8 驗證 |
| 其他人改歸屬可能使正在編輯的段落立即消失 | 保留有焦點／組字中的編輯區，結束編輯後才套用篩選；N5、N11 驗證 |

## 操作限制與上線事項

- 須一併部署新版 database.rules.json 及前端（SW v18）。本次沒有修改線上 Firebase 或推送部署。
- 沿用既有信任課程參與者模型，不提供可信的講師／組別身分授權；介面限制不等於資料庫跨組隔離。
- 首頁登入及載入課程仍需連線。已開啟記事本可在斷線後輸入；離線暫記會在恢復連線、重新載入課程後接續，不代表整個 PWA 已支援首次離線登入。
- 手機注音／倉頡測試目前為 composition 事件模擬，仍應在實體裝置人工驗收；尚未進行長時間大班壓力測試。
- 合併途中若整個瀏覽器在答案交易之前關閉，講師需重新執行相同合併續作；答案已完成時，保留組下次開啟記事本可完成最後清理。
- 不在多人編輯期間壓縮操作記錄；資料保留至刪組、重置或刪課程。本機舊世代救回資料保留在該瀏覽器，清除網站資料會一併移除。

測試重跑方式見 test/README.md；模組與資料契約見「架構與模組規約.md」。
